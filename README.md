## 📧 Moneta Email Sync

### Turn financial emails into structured transaction data.

**Moneta Email Sync** is an open-source developer tool designed to process financial emails and turn useful information from those emails into structured transaction data.

```text
Financial Email
      ↓
Email Provider
      ↓
Email Parser
      ↓
Transaction Data
      ↓
Your Application
```

It is designed so developers can integrate email-based transaction importing into their own applications.

**Repository:**
👉 [github.com/cadinlafon/Moneta-Email-Sync](https://github.com/cadinlafon/Moneta-Email-Sync)

**Documentation:**
👉 [View the Wiki](https://github.com/cadinlafon/Moneta-Email-Sync/wiki)
